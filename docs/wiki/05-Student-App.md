# Student App

## Platform
React Native + TypeScript Android application.

## Planned screens
- Splash and login
- Home/dashboard
- Live bus tracking
- My route and stops
- Bus details
- Driver information
- Notifications
- Trip status
- Report issue
- Help/safety
- Profile/settings

## Navigation
Primary navigation follows the Figma direction: Home, Track, Route, Alerts/Notifications, Profile.

## Data
Use centralized mock data during UI development. Live tracking is represented as a consumer UI; Driver GPS is implemented in the Driver App and backend flow, not inside the Student App.

## UI reference
The Student App Figma Make design is the primary visual/UX reference for the implementation.
