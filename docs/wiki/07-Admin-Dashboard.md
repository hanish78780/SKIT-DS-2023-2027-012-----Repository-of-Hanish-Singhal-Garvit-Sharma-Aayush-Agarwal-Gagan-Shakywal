# Admin Dashboard

The Admin Dashboard is the web interface for transport administration and monitoring.

## Planned/target functions
- Dashboard overview
- Bus management
- Driver management
- Student/assignment management
- Route management
- Trip monitoring
- Notifications
- Operational status and reporting

## Technology
React + Vite. The dashboard communicates with the backend API and does not connect directly to MongoDB.

Development data should remain mock/test data until authorized college data integration is approved.
