# Development Environment

## Windows Android development
Required tooling includes Git, Node.js, JDK 17, Android Studio, Android SDK/platform-tools, ADB, an Android emulator or device, and React Native tooling.

Known project environment baseline:
- React Native 0.87.1
- Node.js 22.x
- JDK 17
- Android SDK

## Mac
For Android: Node.js, Watchman, JDK 17, Android Studio, Android SDK, ADB, and Git. For iOS later, add Xcode and CocoaPods.

## Validation
Run TypeScript checks, unit tests, and an Android build before submitting app work.
